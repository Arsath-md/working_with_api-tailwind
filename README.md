# Cat Facts Website 🐱

A simple web app that fetches random cat facts using a free public API and styles the page with Tailwind CSS.

---

## Features

- Fetches live data from the Cat Facts API  
- Uses modern `fetch` + `async/await`  
- Clean UI built with Tailwind  
- No build tools required  
- Runs directly in the browser

---

## API Used

**CatFact Ninja API**  
https://catfact.ninja/fact

Response Example:

```json
{
  "fact": "Cats sleep 70% of their lives.",
}
